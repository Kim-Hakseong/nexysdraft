# NexysDraft 키·조작 표 (AutoCAD 호환, draft5)

AutoCAD를 쓰던 사람이 바로 쓸 수 있도록 자주 쓰는 키와 조작을 맞췄다. 앱 안에서는 F1(도움말)로 요약을 볼 수 있다.

## 그리기 보조 (상태줄 알약: SNAP · GRID · ORTHO · POLAR · OSNAP)

| 키 | 기능 | 비고 |
|---|---|---|
| **Shift (누르고 있는 동안)** | 임시 직교 | ORTHO가 켜져 있으면 반대로 잠시 끈다(AutoCAD와 같음) |
| F8 | 직교(ORTHO) 켜기/끄기 | 켜면 POLAR는 꺼진다 |
| F10 | 극좌표 추적(POLAR) 켜기/끄기 | 각도 단위 기본 90°, 명령 `POLAR 45`로 45° 단위. **기본 켜짐**(v0.4.6). 커서가 각도선에서 10픽셀 안이면 그 선 위로 붙고 초록 점선과 `Polar: 길이 < 각도` 라벨이 뜬다. F10과 Alt 단독은 Windows 메뉴 키라서 셸이 가로챈다(메뉴 모드로 들어가 다음 키를 먹지 않음, v0.4.1) |
| F3 | 객체 스냅(OSNAP) 켜기/끄기 | 끝점 □ · 중점 △ · 중심 ○ · 교차점 × · 사분점 ◇ · 삽입점. 스냅이 잡히면 직교·극좌표보다 우선(AutoCAD와 같음) |
| **F11** | 객체 스냅 추적(OTRACK) 켜기/끄기 | **기본 켜짐**(v0.4.6). 점을 찍으라는 단계에서 스냅 점(끝점·중점 등)에 커서를 0.35초 올려 두면 초록 + 표시가 생기고, 그 점의 수평·수직선 근처로 가면 초록 점선을 따라 붙는다. 점선 두 개(또는 극좌표선과 점선)가 만나는 곳은 × 표시와 함께 교점에 붙는다. 같은 점에 다시 올리면 해제. 점선이 보일 때 숫자를 치면 그 점에서 그 거리 |
| F7 | 그리드 표시(GRID) | 간격 기본 10, 명령 `GRID 5`로 변경. 너무 촘촘하면 화면에서만 성기게 그린다 |
| F9 | 그리드 스냅(SNAP) | 점을 그리드 간격에 맞춘다. 명령 `SNAP 5`로 간격 변경 |

상태줄의 알약을 클릭해도 같다. 켜진 알약은 배경과 굵기로 표시한다(색 테두리 없음).

## 명령줄

| 입력 | 기능 |
|---|---|
| 글자를 바로 친다 | 캔버스에 포커스가 있어도 명령줄로 들어간다 |
| Enter / Space | 확정. 아무 명령도 없을 때는 **마지막 명령 반복** |
| Esc | 명령 취소(진행 중인 점 입력은 버린다). 명령이 없을 때는 선택 해제 |
| 우클릭 | 기본 = **시간 감지**(AutoCAD): 250 ms 미만으로 짧게 = Enter(확정·반복), 길게 누름 = 상황 메뉴. `RIGHTCLICK ENTER` = 항상 Enter, `RIGHTCLICK MENU` = 항상 메뉴, `RIGHTCLICK TIMED` = 시간 감지(기억됨) |
| `x,y` | 절대 좌표 |
| `@dx,dy` | 마지막 점 기준 상대 좌표 |
| `@길이<각도` | 마지막 점 기준 극좌표(예: `@100<45`) |
| `길이<각도` | 원점 기준 극좌표 |
| 숫자만 | **직접 거리 입력**: 지금 고무줄 방향(직교·극좌표·Shift 반영)으로 그 길이만큼 |

## 마우스

| 조작 | 기능 |
|---|---|
| 휠 | 커서 위치 기준 줌 |
| 휠 누른 채 드래그 | 팬 (Alt+왼쪽 드래그도 팬) |
| **휠 더블클릭** | 전체 보기(Z E) |
| Shift+휠 드래그 | 아무 동작 없음(AutoCAD에서는 3D 궤도 — 충돌 방지) |
| 빈 곳 클릭 → 마우스 이동 → 다시 클릭 (또는 드래그) | 선택 상자. **오른쪽으로 = 창 선택**(파란 실선): 완전히 안에 든 것만 · **왼쪽으로 = 교차 선택**(초록 점선): 조금이라도 걸친 것 전부. Esc·우클릭 = 상자 취소 (v0.4.6: 클릭–클릭 방식 추가) |
| Shift+클릭 / Shift+드래그 | 선택에 추가·제거 |
| 툴바 양 끝의 패널 버튼 | 왼쪽(파일) / 오른쪽(레이어·속성) 패널 숨기기·보이기. Ctrl+2 = 왼쪽, Ctrl+1 = 오른쪽, Ctrl+0 = 양쪽. 창이 좁으면 툴바는 두 줄로 접힌다 |
| 위쪽 지구본 버튼 | 언어 전환: 한국어(기본) ↔ English. 명령 `LANG KO` / `LANG EN` |
| 텍스트 더블클릭 | 텍스트 편집(Enter 적용, MTEXT는 Ctrl+Enter) |

**자르기·연장 대상**: 선·호·원·폴리선(호 구간 포함). 타원·스플라인은 기준 객체로만 쓰인다(자를 수는 없음). 블록 안의 선은 기준이 되지 않는다.

**아직 없는 것(백로그)**: F(필렛)·AR(배열)·SC(축척)·CHA(모따기), 동적 입력(커서 옆 좌표 입력창), 레이아웃 탭, 블록 삽입 UI.

## 도면 배경 (캔버스 테마)

캔버스 툴바 오른쪽 끝의 **BG** 버튼을 누르면 도면 구역 배경이 AUTO(앱 테마를 따름) → LIGHT → DARK 순서로 바뀐다. 앱 테마와는 따로 기억된다.
색 7(흰/검)은 배경에 맞춰 반전된다. 어두운 배경에서는 검정에 가까운 색을 회색 쪽으로 밝힌다. 선택 강조·스냅 표식·커서·선택 상자 색도 배경을 따라간다.
