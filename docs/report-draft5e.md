# NexysDraft draft5e 보고서 — 기본 도형 추가 → v0.4.4

2026-11-02. 동료 피드백: "기본적으로 도형도 네모 정도는 있어야 하는 것 아니냐." 사각형을 포함해 기본 그리기 명령을 갖췄다.

## 추가한 명령 (AutoCAD 별칭 그대로, 툴바 아이콘도 있음)
| 별칭 | 명령 | 입력 순서 |
|---|---|---|
| **REC** | 사각형(닫힌 LWPOLYLINE) | 첫 모서리 → 반대 모서리(`@가로,세로`도 됨) |
| **A** | 호(3점) | 시작점 → 호 위의 점 → 끝점 |
| **EL** | 타원 | 축의 한 끝 → 다른 끝 → 다른 축 반지름(점 또는 값) |
| **POL** | 정다각형(닫힌 LWPOLYLINE) | 변 수 <4> → 중심 → 반지름(점 또는 값). I = 내접, C = 외접. 값으로 주면 밑변이 수평 |
| **PO** | 점 | 점 |
| **DT**, TEXT | 한 줄 텍스트 | 시작점 → 높이 <2.5> → 회전 <0> → 내용. Enter마다 다음 줄로 내려가고, 빈 줄이면 끝 |
| **T**, MT | 여러 줄 텍스트(MTEXT) | 두 모서리(폭) → 줄마다 입력, 빈 줄이면 끝 |

- 미리보기(고무줄)를 모든 명령에 붙였다.
- 텍스트를 입력할 때는 명령줄의 Space가 확정이 아니라 공백이다. 한글 입력기를 위해 명령줄로 포커스를 옮긴다.
- 텍스트는 현재 텍스트 스타일($TEXTSTYLE, 없으면 Standard)을 쓴다.
- `TEXT`는 AutoCAD처럼 새 텍스트를 만든다. 편집은 `ED`나 더블클릭이다.
- CLI: `rec`, `a`, `el`, `pol`, `po`, `dt`, `mt` (skills/nexysdraft/SKILL.md).
- 툴바: 도형이 늘어 그리기 도구도 편집 도구처럼 아이콘만 보이게 바꿨다. 이름과 별칭은 툴팁에 나오고, 선택된 도구는 이름이 보인다.
