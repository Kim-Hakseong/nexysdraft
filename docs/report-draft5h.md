# NexysDraft draft5h 보고서 — 명령줄에 선 종류·지름/반지름 치수·해치, 예제 도면 → v0.4.8

2026-11-11. draft5g에서 에이전트(Claude Code, Antigravity CLI)에게 정식 도면을 시켜 보니 명령줄에 세 가지가 없어서 약식으로 그렸다.
그 셋을 넣고, 새 명령으로 다시 그린 예제 도면을 배포 zip에 넣었다.

## 넣은 것

| 기능 | 명령 | 전에는 |
|---|---|---|
| 선 종류 | `layer new 이름 색 CENTER2`, `layer set 이름 HIDDEN`, `lt 선종류`(선택한 객체), `ltscale N` | 중심선·숨은선을 실선으로 그리거나 짧은 선 수백 개로 흉내 냄 |
| 지름·반지름 치수 | `ddi 중심 반지름 [각도]`, `dra 중심 반지름 [각도]`, `dli … --text Ø<>` | "160"만 나오고 Ø가 없음 |
| 해치 | `hatch 무늬 [축척] [각도] 점들… [/ 섬…] [/ c 중심 반지름]`, `hatch 무늬 sel` | 단면도를 그릴 수 없음 |

- 선 종류 10가지(CENTER·HIDDEN·DASHED·PHANTOM과 절반 크기 `2`, DASHDOT, DOT), 해치 무늬 7가지(SOLID, ANSI31, ANSI32, ANSI37, LINE, NET, DASH).
- **화면과 PDF도 바뀌었다.** 지금까지는 선 종류가 있어도 화면·PDF에 실선으로 나왔고, 무늬 해치는 테두리만 그렸다. 이제 점선·쇄선과 해치 무늬 선을 그린다. 기존 도면을 열어도 적용된다.
- 점선으로 보이는 선도 내부적으로는 선 하나라서, 점선의 빈 곳을 클릭해도 선택되고 스냅·자르기도 그대로 된다.

## 한계
- 해치 경계는 점으로 준 다각형, 원, 또는 선택한 닫힌 폴리선·원이다. 화면에서 영역을 클릭해 채우는 방식(경계 자동 찾기)은 없다.
- 해치 무늬 선이 4,000개를 넘으면 테두리만 그린다(느려지는 것을 막기 위해).
- 지름·반지름 치수의 문자는 항상 곡선 바깥에 놓인다. 각도·정렬 치수와 지시선은 없다.
- 화면(GUI)에서 선 종류를 고르는 UI는 아직 없다. 명령줄과 에이전트로만 지정한다. 화면에서 보는 것은 된다.
- 블록 안의 BYBLOCK 선 종류는 실선으로 그린다.

## 확인하지 못한 것 (UNVERIFIED)
- 기존 사용자 도면에서 선 종류·해치 무늬가 원래 CAD와 같은 모양으로 보이는지(선 종류 축척이 도면마다 다르다). 열리고 그려지는 것, 성능 관문은 통과했다.
- 구버전 AutoCAD/TrueView에서의 새 객체(지름 치수, 무늬 해치).
