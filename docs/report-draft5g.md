| 객체 스냅 추적 | 새로 만듦, 기본 켜짐 | 스냅 점에 커서를 0.35초 올려 + 표시 → 그 점의 수평·수직 점선을 따라 붙는다(F11) |
| 창/교차 선택 | 있었지만 **드래그로만** 됐다 → 클릭–이동–클릭 추가 | 빈 곳 클릭 후 오른쪽 = 파란 실선 창(완전히 안), 왼쪽 = 초록 점선 교차(걸친 것 전부) |
| 패널 숨기기 | 새로 만듦 | 툴바 양 끝 버튼, Ctrl+2(왼쪽)·Ctrl+1(오른쪽)·Ctrl+0(양쪽). 창이 좁으면 툴바가 두 줄로 접힌다(잘리지 않음) |
| 한국어/영어 | 새로 만듦, 기본 한국어 | 위쪽 지구본 버튼 또는 `LANG KO` / `LANG EN` |
| 에이전트로 그리기 | 스킬 설치 명령 추가 | `NexysDraft.exe --install-skill` 한 번 → Claude Code · Gemini CLI · Antigravity CLI에서 말로 요청 |

자르기·연장의 나머지 조작: Shift+클릭 = 반대 동작, 드래그 = 선에 걸친 것을 한꺼번에(한 번의 실행 취소), `T` = 기준 객체 직접 지정, 커서를 올리면 지워질(늘어날) 부분이 굵게 보인다. 명령줄(헤드리스)은 `tr X,Y …` / `ex X,Y …`.

## 에이전트 연동 방식
- MCP 서버·플러그인을 만들지 않았다. 세 에이전트가 모두 같은 스킬 형식(폴더 + SKILL.md)을 읽고, NexysDraft 명령줄은 "스크립트 파일 → result.json"이라 셸만 있으면 된다.
- `--install-skill`이 스킬 파일에 프로그램 경로를 써 넣어 `~\.claude\skills`, `~\.gemini\skills`, `~\.gemini\config\skills`에 복사한다(docs/agents.md).
- 시험 에이전트가 짚은 문서의 빈틈(파워셸이 프로그램 종료를 기다리지 않음, 상대 경로 기준, 치수를 포함한 범위)을 스킬 문서에 반영했다.

## 한계
- 자르기·연장 대상은 선·호·원·폴리선(호 구간 포함)이다. 타원·스플라인은 기준 객체로만 쓰이고(2048각형 근사, 오차 ≈ 반지름 × 1.2e-6) 자를 수는 없다. 블록 안의 선·문자는 기준이 되지 않는다.
- 만나는 곳이 없는 객체를 자르기로 클릭하면 아무 일도 없다(AutoCAD 빠른 모드는 통째로 지운다 — 실수 방지를 위해 다르게 했다).
- 객체 스냅 추적은 수평·수직만이다(극좌표 각도 추적은 없음).
- 엔진이 내는 상태줄 문구("Saved …", "Undo …")와 저장 점검의 사유 문구는 한국어로 옮기지 않았다.
- 언어를 바꾸면 화면을 다시 불러온다. 도면과 실행 취소 기록은 남고, 보기는 전체 보기로 돌아간다.
