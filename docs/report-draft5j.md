## TRIM / EXTEND (둘이 같은 규칙)
| | 빠른 모드 (기본) | 표준 모드 |
|---|---|---|
| 시작 | TR(또는 EX) → 바로 객체 선택 | TR → 기준 객체 선택 → Enter (아무것도 안 고르고 Enter = 모든 객체) |
| 클릭 | 클릭한 부분을 자름 / 클릭한 쪽 끝을 늘림 | 같음 (고른 기준만 적용) |
| 끌기 | 지나간 자리의 객체를 모두 자름 (자유 곡선 울타리) | 같음 |
| 빈 곳 두 번 클릭 | 두 점을 잇는 울타리 | 교차 상자 |
| 아무것과도 안 만나는 객체 (자르기) | 지움 | 그대로 두고 알림 |
| Shift + 클릭 | 자르기 ↔ 연장 전환 | 같음 |

명령 중에 입력하는 옵션: `T` 기준 객체 지정, `F` 울타리, `C` 교차 상자, `O` 모드 전환(`Q` 빠른 / `S` 표준), `R` 지우기, `U` 실행 취소, Enter·Esc·우클릭 = 끝. 모드는 다음 실행에도 기억한다.

고친 결함: 기준 객체를 지정해도 마우스를 올렸을 때의 미리보기는 "모든 객체 기준"으로 나왔다(코드 한 줄이 주석에 삼켜져 있었음).
