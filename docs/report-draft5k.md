# NexysDraft draft5k 보고서 — 저장한 DWG가 다른 CAD에서 빈 화면, 그립 편집, 트림 방식, 클릭 → v0.4.11

2026-11-12. 사용자·동료 보고 4건.

## 1. 저장한 DWG가 TrueView·nanoCAD에서 "안 열린다"
- **재현**: 이 PC의 nanoCAD 5.0과 DWG TrueView 2027에서 재현했다. 파일은 열리지만 **화면이 비어 있다**. DXF도 같았다.
- **원인**: 저장할 때 "처음 보여 줄 위치(뷰)"를 도면 헤더의 범위 값으로 새로 만들었는데, 실제 도면의 그 값은 낡아서 실제보다 수십 배 넓다(예: 실제 폭 약 1,000인데 36,842). 그래서 도면이 점처럼 작게 나와 빈 화면으로 보였다. 한글 글꼴과는 관계없다.
- **수정**: 원본 파일의 뷰를 그대로 유지한다. 원본 뷰가 없거나(새 도면) 도면이 안 보이는 뷰면 실제 도형에 맞춘다.
- **확인**: 사용자 도면 7개와 새 도면을 열기 → DWG 저장 → nanoCAD로 열어 화면을 판정: 8/8 도면이 보임(원본을 연 것과 같은 크기). TrueView 2027 창에서 2개를 화면으로 확인.
- "베타"라고 표시해 둔 이유: DWG 쓰기는 LibreDWG라는 외부 프로그램이 하고 그쪽이 쓰기 기능을 실험 단계로 분류한다. 이번 결함은 그것과 무관하게 NexysDraft 쪽 문제였다.

## 2. 그립 편집
객체를 선택하면 나오는 네모 점(그립)을 끌거나, 클릭하고 옮긴 뒤 다시 클릭한다.
| 그립 | 동작 |
|---|---|
| 선의 끝 | 그 끝만 움직임(줄이기 / 늘이기) |
| 선의 중간 | 선 전체 이동 |
| 원의 중심 / 사분점 | 이동 / 반지름 변경 |
| 호의 끝 / 중간 / 중심 | 각도 변경 / 반지름 변경 / 이동 |
| 폴리선 꼭짓점 / 변의 중간 | 그 점만 / 그 변만 이동 |
| 문자·블록의 기준점 | 이동 |
스냅·직교·극좌표 추적이 그대로 적용되고, 숫자를 치면 그 거리만큼 움직인다. Esc = 취소. 한 번의 편집 = 실행 취소 한 단계.

## 3. 트림 / 연장
영상(nanoCAD)과 같은 방식을 기본으로 했다: `TR` → 기준 객체 선택(여러 개 가능) → Enter → 자를 부분을 계속 클릭 → Esc까지 유지. `EX`도 같다(경계 선택 → Enter → 늘릴 끝을 계속 클릭). 기준을 고르지 않고 Enter를 치면 모든 객체가 기준이다. v0.4.10의 "빠른 모드"는 명령 중 `O`로 바꿀 수 있다.

## 4. 클릭이 씹히는 문제 (추가 개선)
- 측정: 클릭 한 번의 처리 시간은 큰 도면(25,652 객체)에서 중앙값 16 ms, 화면 갱신 3.5 ms로 병목이 아니었다.
- 급하게 누르고 뗀 클릭(0.22초 안)은 18픽셀까지 미끄러져도 클릭으로 인정한다(전에는 6픽셀을 넘으면 드래그 상자가 됐다).
- 클릭하면 선택될 객체를 커서를 올렸을 때 미리 굵게 보여 준다.
