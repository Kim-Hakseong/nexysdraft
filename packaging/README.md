# NexysDraft 0.4.0 — 사내용 경량 2D CAD (포터블)

DWG·DXF 도면을 열어 보고, 고치고, DXF/DWG/PDF로 저장하는 프로그램입니다. **설치가 필요 없습니다.**

## 실행
1. zip을 아무 폴더에 풉니다. `NexysDraft.exe`와 `tools\` 폴더가 **같은 폴더에** 있어야 합니다(`tools\libredwg\`가 DWG 변환기).
2. `NexysDraft.exe`를 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누릅니다(코드 서명 없는 사내 배포본).
3. 도면을 창에 끌어다 놓거나 **OPEN**(Ctrl+O). Windows 10/11 64비트, Edge WebView2 런타임(윈도우 11 기본 포함).

## 지원 형식
| 열기 | 저장 |
|---|---|
| DWG R13 ~ 2018 (AutoCAD 2018 형식 포함), DXF R12 ~ 2018 | DXF(2013 이하 원본은 그 버전 그대로·고치지 않은 부분도 원본 그대로, 2018 원본은 R2000), DWG **R2000**, PDF(검색 가능, 시트별 자동 분할) |

## 이런 때 쓰세요
- **nanoCAD 5가 못 여는 2018 DWG**: NexysDraft로 열어 **DWG(R2000)** 또는 DXF로 저장하면 nanoCAD 5에서 열립니다(사내 확인: u02·u04 형식 도면 RECOVER 없이 열림). nanoCAD 5는 DXF를 2013(AC1027) 형식까지만 열기 때문에, 2018 원본의 DXF는 기본으로 **R2000**으로 저장합니다(저장 창의 **DXF 버전**에서 '원본 유지'를 고를 수 있음).
- **nanoCAD에서 한글이 ?로 보일 때**: 저장 대화상자의 **"nanoCAD 글꼴 호환"**(기본 켜짐)이 이 PC에 없는 글꼴(예: GulimChe.ttf, whgtxt.shx)을 쓰는 한글 스타일을 Windows 글꼴 파일·영문 이름(gulim.ttc + Gulim, batang.ttc + Batang, malgun.ttf + Malgun Gothic)으로 바꿉니다. 글꼴이 있는 스타일은 건드리지 않습니다.
- **도면을 PDF로**: PDF 버튼 또는 Ctrl+P. 파일 세 종류가 함께 만들어집니다. 용지는 도면의 플롯 설정(대부분 A3)을 따르고, 글자는 PDF 검색(Ctrl+F)이 됩니다. 자세한 구성은 `docs\pdf-output.md`에 있습니다.
  - `파일명.pdf`: 시트마다 1쪽인 합본
  - `파일명__001.pdf…`: 시트별 개별 파일
  - `파일명__overview.pdf`: 전체를 1장에 담은 개요
  - 쪽이 1개뿐인 도면은 합본만 만듭니다(나머지 둘은 내용이 같음).

## 조작 (AutoCAD 방식)
AutoCAD에서 자주 쓰던 키를 그대로 씁니다. 전체 표는 **`docs\keys.md`**에 있습니다.
- **Shift를 누르고 있는 동안 직교**: 선을 그릴 때 수평·수직으로 고정됩니다.
- F8 직교, F10 극좌표 추적(90°), F11 객체 스냅 추적, F3 객체 스냅, F7 그리드, F9 그리드 스냅. 화면 아래 상태줄의 SNAP·GRID·ORTHO·POLAR·OSNAP·OTRACK 알약을 눌러도 됩니다.
- **초록 점선 가이드**(기본 켜짐): 선을 그릴 때 수평·수직 근처로 가면 점선에 붙습니다(극좌표 추적). 끝점·중점 같은 스냅 점에 커서를 잠깐(0.35초) 올려 + 표시가 생기면, 그 점과 수평·수직으로 맞는 위치에서도 점선이 나타나 붙습니다(객체 스냅 추적).
- **선택 상자**: 빈 곳을 클릭하고 마우스를 옮긴 뒤 다시 클릭합니다(드래그도 됨). **오른쪽으로 벌리면 파란 실선 = 창 선택**(상자 안에 완전히 들어온 것만), **왼쪽으로 벌리면 초록 점선 = 교차 선택**(조금이라도 걸친 것 전부). Esc로 취소.
- **자르기 `TR` / 연장 `EX`**: `TR` 후 지울 부분을 클릭하면 양옆의 다른 객체와 만나는 곳까지 잘립니다(올려 두면 지워질 부분이 굵은 점선으로 보임). `EX` 후 늘릴 끝 쪽을 클릭하면 가장 가까운 객체까지 늘어납니다. Shift+클릭은 반대 동작, 드래그는 선에 걸친 것을 한꺼번에, `T`는 기준 객체를 직접 고르기입니다. 대상은 선·호·원·폴리선입니다.
- 글자를 치면 바로 명령줄로 들어갑니다. Enter·Space는 확정, 아무 명령도 없을 때는 마지막 명령을 반복합니다. Esc는 취소입니다. 우클릭은 짧게 누르면 확정·반복, 길게(0.25초 이상) 누르면 메뉴입니다(`RIGHTCLICK ENTER`/`MENU`/`TIMED`로 바꿈).
- 좌표는 `100,50`, `@30,0`, `@100<45`로 입력합니다. 숫자만 치면 지금 방향으로 그 길이만큼 그립니다.
- 휠은 커서 기준 줌, 휠 드래그는 팬, **휠 더블클릭은 전체 보기**입니다. `Z` 다음 `P`는 이전 보기, `RE`는 재생성, `R`은 다시 그리기입니다.
- 측정: `DI`는 두 점 사이 거리·각도, `ID`는 점 좌표입니다. 결과는 명령줄에만 나옵니다.
- 그리기: `L` 선, `PL` 폴리선, `C` 원, **`REC` 사각형**, `A` 호(3점), `EL` 타원, `POL` 다각형, `PO` 점, `DT` 한 줄 텍스트, `T` 여러 줄 텍스트, `DLI` 치수. 툴바 아이콘으로도 시작합니다(마우스를 올리면 이름이 보입니다).
- 저장한 DWG(R2000)·DXF는 Autodesk DWG TrueView 2027에서 열리는 것을 확인했습니다. 더 오래된 AutoCAD/TrueView는 확인하지 못했습니다.

## 화면 넓게 쓰기 · 언어
- 도면 툴바 **양 끝의 패널 버튼**으로 왼쪽(파일)·오른쪽(레이어·속성) 패널을 숨기거나 다시 보입니다. Ctrl+2 = 왼쪽, Ctrl+1 = 오른쪽, Ctrl+0 = 양쪽. 창이 좁으면 툴바가 두 줄로 접혀 도구가 잘리지 않습니다.
- 기본 언어는 한국어입니다. 위쪽 **지구본 버튼**(또는 명령 `LANG EN` / `LANG KO`)으로 영어와 바꿉니다. 바꾸면 화면을 다시 불러오며 도면은 그대로입니다.

## 도면 배경
도면 위쪽 툴바 오른쪽 끝의 **BG** 버튼으로 도면 구역만 밝게/어둡게 바꿀 수 있습니다(AUTO = 앱 테마를 따름). 앱 테마(THEME, Ctrl+T)와 따로 기억됩니다. 흰/검 색(색 7)은 배경에 맞춰 자동으로 바뀝니다.

## DWG 저장 정책
저장할 때 **사전 점검** 창이 뜹니다.
- **DWG 저장 가능**: 점검 통과. DWG 버튼이 기본입니다.
- **DXF 권장**: 다른 CAD에서 열리지 않을 것으로 보이는 객체(래스터 이미지, R2000 이후 객체)가 있거나, 동적 블록이 있는 도면(DWG는 열리지만 동적 매개변수가 빠짐). 사유 줄을 **더블클릭**하면 해당 객체로 확대됩니다. 열리지 않을 것으로 보이면 DWG 버튼에 **(beta)**가 붙습니다.
- **래스터 이미지만** 문제인 도면은 **"IMAGE n개 제외하고 DWG 저장"** 버튼이 추가로 나옵니다(이미지가 빠진 DWG, 기본은 DXF).
- 이름 없는 블록·깨진 블록 참조, 매듭 수가 잘못된 스플라인은 DWG에서 빠진다는 안내만 하고 막지 않습니다.
- DWG 저장은 보통 몇 초입니다(10만 객체 약 6초). 상태줄에 경과/예상 시간이 보이고 **CANCEL SAVE**로 취소할 수 있습니다.

## 명령줄 (자동화)
```
NexysDraft.exe --script job.txt --out 결과폴더 --json
```
`job.txt` 예: `open C:\도면\a.dwg` / `replace PT-101 PT-201` / `save C:\도면\a_rev.dwg` / `save C:\도면\a_rev.dxf --ver keep` / `pdf C:\도면\a.pdf`. 결과는 `결과폴더\result.json`. **AI 에이전트로 그리기**: `NexysDraft.exe --install-skill`을 한 번 실행하면 Claude Code · Gemini CLI · Antigravity CLI(agy)에 스킬이 설치되어, "200×120 판에 구멍 4개 그려서 DWG로 저장해줘"처럼 말로 시킬 수 있습니다(지우기: `--install-skill --uninstall`). 문법 전체: `skills\nexysdraft\SKILL.md`.

## 알려진 제한
- DWG 쓰기는 R2000만(LibreDWG 소스 빌드 0.14.8679). 사내 실도면 7개 중 6개가 다른 CAD(ODA 기반 검사)에서 그대로 열렸고, 래스터 이미지가 든 1개는 열리지 않았습니다 → 사전 점검이 DXF를 권하고, 이미지를 뺀 DWG도 고를 수 있습니다.
- 동적 블록은 DWG(R2000)로 저장하면 정적인 모양으로만 남습니다. 동적 블록 편집 기능은 없습니다.
- 페이퍼 스페이스(배치)는 보존되지만 화면에는 모형 공간만 보입니다(배치 탭은 다음 버전).
- 필렛·모따기·배열·해치 만들기·블록 편집·3D는 없습니다. 자르기·연장은 선·호·원·폴리선만 됩니다(타원·스플라인·블록 안의 선은 자를 수 없음).
